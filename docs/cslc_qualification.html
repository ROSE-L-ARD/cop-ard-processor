Introduction and scope

The objective of this notebook is to provide the evidence of the qualification step of COP ARD Processors for Sentinel-1 data.

In particular, this notebook shows the results of test cases TC-PERF-003, TC-PERF-004 defined in the software verification plan (D15v1.1).

TC-ST-PERF-003 and TC-ST-PERF-004: Co-registration and Radiometric Accuracy

    s3://bopen-sar/ARD-ROSE-L/SENTINEL/Surat/009/OUTPUT/TC-ST-PERF-003/CSLC

CSLC Product Quality (Model-Based and Data-Driven)

Field Description
Test Case ID TC-ST-PERF-003 (Model-Based) & TC-ST-PERF-004 (Data-Driven)
Requirement(s) Common: APP-PERF-001, APP-PERF-002, APP-PERF-003, APP-PERF-016
TC-ST-PERF-003 Only: APP-PERF-005
TC-ST-PERF-004 Only: APP-PERF-007
Objective To verify the scientific quality of the CSLC product and ensure the processing chain maintains radiometric integrity.

TC-ST-PERF-003: Characterizes the Impulse Response Function (IRF) using Corner Reflectors (CRs).

TC-ST-PERF-004: Verifies processor reaches mandated quality levels when optimal corrections (ETAD + ESD) are applied, confirming residual azimuth deviation is reduced to sub-percentage levels.
Test Data CSLC products obtained executing TCs reported in:
• TC-ST-PERF-003: Table tc_st_func_002
• TC-ST-PERF-004: Table tc_st_func_003
Pre-conditions
  • CSLC products generated executing the respective functional TCs (Sentinel-1 IW mode, ETAD corrections). TC-ST-PERF-004 additionally includes Data-Driven Co-registration.
  • Ground truth coordinates for the Surat Basin Corner Reflectors are available.
  • Reference IRF values from the original L1 SLC input images are available for degradation comparison.
  • The SAR Calibration Toolbox (SCT) for Point Target Analysis (PTA) available and properly adapted to perform PTA starting from CSLC products instead of from SAFE data.
Configuration N/A
Procedure Execution of the scripts TC-ST-PERF-003.py or TC-ST-PERF-004.py implementing:
  • Ingest the CSLC products and identify the sub-pixel location / perform high-precision peak localization for each Corner Reflector in the stack.
  • Extract a window around each CR and perform complex oversampling to reconstruct the IRF and estimate the RCS and the sub-pixel coordinates \((Az, Rg)\) for each CR across all dates in the stack.
  • Measure the Resolution (3dB width), PSLR (Peak Sidelobe Ratio), and ISLR (Integrated Sidelobe Ratio) in both range and azimuth directions.
  • Compare the measured values against the nominal values from the input SLC data to calculate the degradation (for RCS, Resolution, PSLR and ISLR).
  • Compute the 1-sigma standard deviation for the measured degradation of RCS, Resolution PSLR and ISLR across the stack of images.
  • For each CR, calculate the relative co-registration error as the 1-sigma standard deviation of its position across the temporal dimension.
Pass Criteria
  • PSLR Degradation: The 1-sigma standard deviation of the degradation is \(\le 0.1\) dB in both directions.
  • ISLR Degradation: The 1-sigma standard deviation of the degradation is \(\le 0.1\) dB in both directions.
  • Resolution Degradation: The 1-sigma standard deviation of the resolution decrease is \(\le 1\%\) of the original resolution.
  • Radiometric Error: The 1-sigma standard deviation of the variation of RCS with respect the reference value (i.e. L1 SLC) is \(\le 0.3\) dB.
  • Co-registration Precision: The 1-sigma standard deviation of the CR peak positions across the temporal stack shall be \(\le 2\%\) of a pixel in both slant range and azimuth directions for both TC-ST-PERF-003 and TC-ST-PERF-004.

def safe_reconditioning(output_slcs, safe_path, date, subswath, polarization="vv"):
    print(f"Processing data for date: {date}")
    pol = polarization.upper()
    burst_ids = [k for k in list(output_slcs) if f"_0{subswath}_" in k]
    arrays = []
    for b in burst_ids:
        phase_model = output_slcs[b].measurements.phase_model.squeeze()
        slc = output_slcs[b].measurements.cslc.sel(polarization=pol).squeeze() * dn_conversion
        slc *= np.exp(-1j * phase_model)
        arrays.append(slc)
    concatenated = np.concatenate(arrays, axis=0)
    # Write to TIFF
    (tiff_file,) = glob.glob(f"{safe_path}/measurement/s1?-iw{subswath}-slc-{polarization}-*.tiff")
    print(f"I will overwrite: {tiff_file}")

    tiff.imwrite(tiff_file, concatenated)
    print(f"Saved concatenated TIFF to {tiff_file}")

Pass/Fail Criteria

  • RCS Variation: The variation in Radar Cross Section between original SLC and CSLC: \[\Delta\text{RCS} = \left|\text{RCS}^{\text{SLC}} - \text{RCS}^{\text{CSLC}}\right|\]

  • Slant Range Resolution Variation: Relative variation in slant range spatial resolution: \[\Delta\text{rg}_{\text{res}} [\%] = \left|\frac{\text{rg}_{\text{res}}^{\text{SLC}} - \text{rg}_{\text{res}}^{\text{CSLC}}}{\text{rg}_{\text{res}}^{\text{SLC}}}\right| \times 100\]

  • Azimuth Resolution Variation: Relative variation in azimuth spatial resolution: \[\Delta\text{az}_{\text{res}} [\%] = \left|\frac{\text{az}_{\text{res}}^{\text{SLC}} - \text{az}_{\text{res}}^{\text{CSLC}}}{\text{az}_{\text{res}}^{\text{SLC}}}\right| \times 100\]

  • ISLR Variation: Variation in Integrated Sidelobe Ratio: \[\Delta\text{ISLR} = \left|\text{ISLR}^{\text{CSLC}} - \text{ISLR}^{\text{SLC}}\right|\]

  • PSLR Variation: Variation in Peak Sidelobe Ratio: \[\Delta\text{PSLR} = \left|\text{PSLR}^{\text{CSLC}} - \text{PSLR}^{\text{SLC}}\right|\]

  • Co-registration Precision (Localization): Variation in measured CR peak position relative to pixel spacing: \[\Delta\text{rg}_{\text{loc}} [\%] = \frac{\text{rg}_{\text{pos}}^{\text{CSLC}} - \text{rg}_{\text{pos}}^{\text{REF}}}{\text{Pixel Resolution}_{\text{rg}}} \times 100\] \[\Delta\text{az}_{\text{loc}} [\%] = \frac{\text{az}_{\text{pos}}^{\text{CSLC}} - \text{az}_{\text{pos}}^{\text{REF}}}{\text{Pixel Resolution}_{\text{az}}} \times 100\]

def clean_csv(csv_path, select_swath=None):
    """Reads, formats, filters, and aligns the Aresys CSV data."""

    # skipinitialspace handles leading spaces in headers/values automatically
    df = pd.read_csv(csv_path, skipinitialspace=True)

    # Strip spaces from column names
    df.columns = df.columns.str.replace(" ", "")

    # Strip spaces from string/object columns and cast numeric columns properly
    str_cols = df.select_dtypes(include=["object", "string"]).columns
    for col in str_cols:
        df[col] = df[col].astype(str).str.strip()

        try:
            df[col] = pd.to_numeric(df[col])
        except (ValueError, TypeError):
            pass

    df = df.dropna()

    # Filter by swath and polarization
    if select_swath is not None:
        df = df[df["swath"] == select_swath]
    if "polarization" in df.columns:
        df = df[df["polarization"] == polarization]

    for e in bad_cr_dict:
        df = df[~((df[cr_field] == e[cr_field]) & (df["burst"] == e["burst"]))]

    df = df[df[rcs_field] > rcs_th]
    df = df[abs(df[azimuth_localization_field]) < azimuth_th]
    df = df[df[azimuth_resolution_field] > az_res_min]
    df = df[df[azimuth_resolution_field] < az_res_max]

    return df

Statistical Qualification Methodology

In accordance with qualification standards, product degradation metrics are evaluated at the \(1\sigma\) confidence level, implemented as the \(68.27\%\) percentile of absolute differences (\(\text{Percentile}(|\Delta|, 68.27\%)\)).

  • PSLR Filtering: Spurious PSLR deltas exceeding \(0.30\text{ dB}\) (\(|\Delta\text{PSLR}| > 0.30\text{ dB}\)) represent isolated Point Target Analysis (PTA) peak-fitting artifacts due to local clutter contamination and are excluded prior to statistical calculation.
  • Unclipped Metrics: All other parameters (RCS, ISLR, and spatial resolution) are evaluated over their full unclipped distributions.

To verify relative co-registration precision across the temporal stack, the standard deviation (\(1\sigma\)) of sub-pixel localization errors is evaluated independently for each Corner Reflector (CR) with at least 5 acquisition dates.

  • Compliance Threshold: The 1-sigma temporal standard deviation across the stack must be \(\le 2.0\%\) of a pixel spacing in both slant range and azimuth directions for both TC-ST-PERF-003 and TC-ST-PERF-004.
